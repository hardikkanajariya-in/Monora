Monora

Screen recording for Windows.

Monora captures one or more displays with optional system and microphone audio, encodes to H.264 and AAC in MP4, and is available as a portable package or Windows installer. The application is built with Tauri and Rust and does not require external encoding tools on the target system.

Features
Multi-monitor Windows Graphics Capture for physical displays — combined canvas or separate MP4 per screen.
Audio WASAPI loopback for desktop sound plus selectable microphone, mixed with clipping protection.
Hardware H.264 Media Foundation hardware encoders when available, with a software fallback path.
Portable deployment Run from any directory. Settings are stored in config/; logs are written to logs/.
System tray and shortcut Runs in the notification area. Use Ctrl+Shift+R to start or stop recording.
Open source Released under the MIT license. Source is available on GitHub.
