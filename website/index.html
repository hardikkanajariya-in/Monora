Monora — Simple Recorder

Record your screen like it's 2009 — encode like it's 2026.

Monora (Simple Recorder) is a portable Windows app built with Tauri and Rust. Capture one or more monitors with system audio and microphone, export H.264 + AAC MP4, and run from a folder — no installer, no FFmpeg bundle, no Python runtime.

Features
Multi-monitor Windows Graphics Capture for physical displays — combined canvas or separate MP4 per screen.
Audio WASAPI loopback for desktop sound plus selectable microphone, mixed with clipping protection.
Hardware H.264 Media Foundation encoders when your GPU drivers support them; sensible software fallback.
Portable Drop the folder anywhere — settings in config/, logs in logs/.
Tray + hotkey System tray integration and global Ctrl+Shift+R to toggle recording.
Open source MIT licensed. Built with Tauri 2, Rust, and TypeScript — contributions welcome.
