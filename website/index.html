Features
Multi-monitor Windows Graphics Capture for physical displays — combined canvas or separate MP4 per screen.
Audio WASAPI loopback for desktop sound plus selectable microphone, mixed with clipping protection.
Hardware H.264 Media Foundation hardware encoders when available, with a software fallback path.
Portable deployment Run from any directory. Settings in config/; logs in logs/.
System tray and shortcut Notification area. Ctrl+Shift+R to start or stop recording.
Source MIT license. Repository on GitHub.
