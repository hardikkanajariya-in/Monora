# Contributing

```bash
npm install
npm run tauri dev
```

PRs: one topic per change, run `npm run build` (and `npm run tauri build` when Rust changes). Bug reports need Windows version, steps, and relevant log lines from `logs/simple-recorder.log`.

Icon source: `assets/brand/monora-icon.svg` — `npm run icons` after edits.

Contributions are MIT-licensed like the project.
